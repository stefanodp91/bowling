# Open-source release

> Boundary: what makes the repository ready to be shared: README, licences, notices, changelog, the
> static build, the final checks. NOT covered: publishing it anywhere (a human decision).

## Purpose

Someone from the audience clones the repository at home. Without help, they must be able to run the
demo, understand how it was built, and rebuild it with their own agent.

## Rules

1. **README.md**, for that person: what the demo is (one paragraph and a screenshot generated with
   the shot tool and committed), how to run it (`npm ci`, `npm run dev`), how it was built (the six
   prompts, the wiki as specification, the review queue, gates, headless runs — with links), how to
   rebuild it from zero (start a fresh agent session on [`BUILD.md`](../../BUILD.md) from the round
   zero commit), and the current `npm run stats -- --md` table.
2. **LICENSE**: MIT (already present from round zero). **THIRD_PARTY_NOTICES.md** generated by
   `npm run notices` from the licence fields and files of every production dependency, including
   both engines, Babylon.js, Havok and Reactylon — with a line of thanks to Reactylon's author for
   making React on Babylon.js possible. `check-notices` fails if a production dependency is missing.
3. **CHANGELOG.md**: the story of the build, one entry per built page, written by prompt 4 when
   handoffs close.
4. **Static build:** `npm run build` produces `game/dist/`; `npm run preview` serves it locally and
   the headless pilot passes against it too.
5. **Final checks:** `npm run check:full` green; `check-no-foreign-refs` green on the full history;
   no `planned` page left except those a human explicitly deferred in `review.md`.

## Acceptance criteria

1. [auto] `npm run check:full` passes on a clean clone after `npm ci`.
2. [auto] `check-notices` passes and its `--selftest` rejects a fixture with an unlisted dependency.
3. [auto] `npm run pilot -- --tracks lane-01 --skill perfect` passes against `npm run preview`.
4. [auto] Every relative link in README.md resolves.
5. [human] A person who was not involved follows README.md and runs the demo without asking anything.
