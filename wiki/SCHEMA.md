# Wiki schema

> Boundary: the format of a wiki page, checked by `npm run wiki:lint`. NOT covered: why the wiki is
> the specification and how a page moves through its states ([wiki as spec](method/wiki-as-spec.md)).

## Page types

| `type` | What it is | Has `status` |
|---|---|---|
| `spec` | Something that must exist in the code: a tool, a model, a behaviour | yes |
| `concept` | A rule or an explanation that holds across pages (this file, the method) | no |
| `record` | A verification record written with [prompt 6](../prompts/6-verification-record.md), under `records/` | no |

## Front matter

Every page except the generated [`index.md`](index.md) starts with YAML front matter:

```yaml
---
title: Short title — what it covers        # required
type: spec | concept | record              # required
status: planned | built | approved         # required for spec, forbidden otherwise
approved_on: 2026-11-02                    # only with status: approved; written by a human
depends_on: [workspace/monorepo.md]        # spec only: pages that must be built first (paths from wiki/)
canonical: [game/src/domain/run.ts]        # spec only: the files that implement it; empty while planned
verified: 2026-10-26                       # the last date the page was checked against the code
---
```

## Sections of a `spec` page, in this order

1. `# Title`, then a `> Boundary:` line: what the page covers and what it does NOT cover.
2. `## Purpose` — why it exists, in a few lines.
3. `## Rules` — what must be true. Numbers carry their unit and their origin.
4. `## Acceptance criteria` — a numbered list. Each criterion starts with `[auto]` (a command, a
   gate or a test decides it) or `[human]` (a person decides it by looking). **Owned by the human:
   an agent never edits this section** ([AGENTS.md](../AGENTS.md), rule 3).
5. `## References` — links and facts found with web search (prompt 1, step 2). Never downloaded
   files.
6. `## Rounds` — one entry per self-approval round (prompt 1, step 5): date, what was looked at,
   what was wrong, what changed.
7. `## Canonical files` — optional prose about the files listed in `canonical:`.

## Links and names

- Links are relative Markdown links; `wiki:lint` fails on a broken one.
- File names are lowercase kebab-case. Records are `records/<topic>-<yyyymmdd>.md`.
- [`index.md`](index.md) is generated by `npm run wiki:index` once that script exists; until then it
  is maintained by hand in the same format.
